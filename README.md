# Travel Destination Explorer

A responsive travel website built for the CO2 Retake Exam.

## Project Description

Interactive travel destination explorer allowing users to search, filter, and view detailed information about various travel locations.

## Key Features

- Hero section with search functionality
- Responsive destination grid with filter options (Beaches, Mountains, Cities)
- Detailed destination page with image carousel
- Contact form with real-time JavaScript validation
- Fully responsive design using Bootstrap 5

## Technologies Used

- HTML5
- Bootstrap 5 (CSS Framework)
- JavaScript (Vanilla)
- GitHub Pages (Deployment)
